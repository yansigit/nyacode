# Harmless attachment acceptance corpus

These generated files contain only fictional verification codes. PNG, JPEG and
WebP display different codes as pixels; PDF contains one text page; the text
fixture contains valid UTF-8 accents and a symbol. The harness verifies all five
SHA-256 digests before uploading. Its prompt does not contain the expected code.
Each response must match the code for that turn's attachment exactly and pass
authoritative saved-conversation retrieval.

The images were generated with Pillow 10.2.0 and the repository's licensed
DejaVu Sans Mono font. The PDF is a small original document with a conventional
cross-reference table. No external or personal file is included.
